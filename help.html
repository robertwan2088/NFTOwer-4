常见问题

1. 点击页面右上角的"连接钱包"按钮
2. 选择您常用的钱包（MetaMask、WalletConnect等）
3. 授权连接后即可开始使用平台功能
4. 首次使用建议完成身份验证以提升账户安全等级

1. 浏览市场页面，找到您喜欢的NFT
2. 点击进入NFT详情页，查看价格和相关信息
3. 点击"立即购买"按钮
4. 确认交易信息并在钱包中签名完成支付

1. 前往"质押中心"页面
2. 选择适合您的质押池（自由区或专区）
3. 点击"前往质押"，选择要质押的NFT
4. 确认质押数量和期限，完成质押
5. 收益将按日发放到您的账户

1. 进入"资产中心"页面
2. 点击"提现"按钮
3. 选择提现币种和金额
4. 输入收款地址（请确保地址正确）
5. 完成安全验证后提交申请

• 购买NFT：免手续费
• 出售NFT：2.5% 平台手续费
• 质押NFT：1% 手续费
• 提现：根据币种不同，手续费有所差异，具体以页面显示为准
